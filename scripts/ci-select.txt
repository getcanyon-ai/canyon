# scripts/ci-select.txt: scripts/ci-select.sh's table. Each line is a path pattern, then the suites of
# scripts/ci-suite.sh a change to it runs, as shell patterns of their names: * for every suite, - for none beyond the
# five every change runs (lint, tidy, web, test-rest, gitleaks) and the stack suites whose .github/suites list it
# reaches. A pattern is a git :(glob) pathspec, as in .github/suites: ** crosses directories, * stays within one, and
# no pattern holds a space. A changed path no line matches runs every suite. internal/tools/suites keeps it honest:
# every tracked file matches a line, and the Go each suite's tests compile is on lines that name it.
