# Try Canyon: an all-in demo on one machine

**Not for production.** This chart runs Canyon and everything it needs on a single node. Its guide,
every value it needs and its hooks are on the docs site:
[Try it on Kubernetes (Helm)](https://www.getcanyon.ai/docs/self-host/helm/). To run Canyon for
real, [install it on Kubernetes](https://www.getcanyon.ai/docs/self-host/kubernetes/).
